# Najla Almutairi — data analyst portfolio

Static bilingual portfolio prepared for GitHub Pages. Open `index.html` or serve the directory using `python3 -m http.server 8000`.

## Publish

Create a public repository named `Just_Najla` in the chosen GitHub account. Upload the contents of this folder to the repository root. In **Settings → Pages**, set **Build and deployment → Deploy from a branch → main / (root)**. The URL will be `https://USERNAME.github.io/Just_Najla/`.

The workforce planning case study describes an actual dashboard supplied as a screenshot by the user. The website includes a blurred crop from the original screenshot; the generated recreation has been removed. Original text, figures and unit names are not readable in the published asset. The source image and workbook are intentionally excluded. Do not add their details to the published site without a confidentiality review.

The interactive inventory project uses synthetic data. It is an illustrative analysis, not a record of Najla's employer or actual work. Recreate the CSV with `python3 generate_data.py`.

This public edition includes Najla's email address at the user's explicit request. It excludes her phone number and original résumé PDF.
